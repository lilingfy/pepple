\chapter{项目进度}

\section{本章作用}

本章集中记录 Pebble 在当前代码库中的真实实现状态、已完成能力、技术落地细节与待完善项。它与前八章的区别在于：前八章主要围绕设计意图与系统结构展开论述，本章则把论述锚定在代码库中可直接观察到的文件、接口、测试与数据对象上。

本章的事实来源是当前工作区中的源代码、数据库迁移记录、测试文件与 OpenSpec 变更归档。所有列出的能力都以"已可运行"或"已可验证"为前提，不超前宣称尚未实现的特性。

\section{已完成的能力面}

\subsection{前端交互层}

当前代码库中已具备以下可直接运行的前端页面与组件：

\begin{itemize}
  \item 首页：包含 Hero 主视觉、统计卡片、功能入口、读心翻译演示、模拟陪练场景卡片、急救呼吸鹅卵石动画与滚动触发动效。
  \item 读心翻译页：支持文本输入、情绪状态条展示、解码请求触发、分析结果展示（表面语义、潜台词、情绪得分）与三档回复建议（A/B/C）。
  \item 模拟陪练场页：支持场景选择（职场越界、亲密关系、社交应对）、回合式对话、右侧实时分析面板（情绪得分、标签、即时反馈、注意点）与会话结束总结。
  \item 急救呼吸页：支持 4-7-8 呼吸节奏引导、倒计时、暂停/重置、沉浸背景动画与波纹扩散效果。
  \item 个人中心与关系管理：支持关系对象创建、编辑、列表展示，以及当前关系选择对翻译分析路径的上下文穿透。
  \item 设计系统组件库：包含玻璃拟态卡片（GlassCard）、鹅卵石按钮（PebbleButton）、状态胶囊（StatusPill）、呼吸圆（BreathingOrb）、页面壳（PageShell）等 9 个以上可复用组件。
\end{itemize}

此外，后端还包含以下策略层能力：

\begin{itemize}
  \item PII 脱敏：在调用 LLM 前对电话、邮箱、姓名等敏感信息执行自动替换。
  \item 限流与超时：按 session 和 IP 双重约束限流；LLM 调用设置硬超时并具备降级路径。
  \item 确定性 fallback：当 LLM 供应商不可用时，后端退回基于规则的本地启发式分析，保证基础功能不中断。
  \item 匿名会话管理：通过 \texttt{guest\_session\_id} cookie 为未登录用户提供最小身份与部分持久化能力。
\end{itemize}

\subsection{测试覆盖}

当前测试体系分为前端测试与后端测试两层：

\begin{itemize}
  \item 前端测试：50 个测试文件，覆盖首页、翻译页、陪练场、呼吸页、个人中心、设计系统组件与自定义 Hook，累计约 448 个测试用例。
  \item 后端测试：6 个测试文件，覆盖 schema、contracts、错误处理、会话管理、解码服务与路由适配器。
\end{itemize}

测试框架采用 Vitest，前端测试在 jsdom 环境下运行，后端测试在 Node 环境下运行。

\section{技术实现状态}

\subsection{设计系统落地}

设计系统已通过 Tailwind CSS 配置、CSS 变量与 TypeScript 令牌文件三重方式落地：

\begin{itemize}
  \item 颜色令牌：\texttt{pebble-rock}、\texttt{pebble-healing}、\texttt{pebble-bg}、\texttt{pebble-accent}、\texttt{pebble-warn} 已定义并在组件中消费。
  \item 字体系统：Noto Serif SC（标题）、Noto Sans SC（正文）、Public Sans（英文显示）已配置。
  \item 圆角系统：有机鹅卵石形状（\texttt{border-radius: 60\% 40\% 70\% 30\% / 40\% 50\% 60\% 40\%}）及其变体已实现。
  \item 动画系统：呼吸动画（19 秒周期）、浮动背景动画（12 秒周期）与页面过渡动画均已通过 CSS keyframes 或 Framer Motion 实现。
\end{itemize}

\subsection{OpenSpec 变更归档}

项目已通过 OpenSpec 工作流完成 4 个变更的归档：

\begin{itemize}
  \item 建立 Pebble 设计系统（TB-005）
  \item 构建 Pebble 首页（TB-001）
  \item 构建 Pebble 读心翻译器（TB-002）
  \item 后端 BFF 与接口技术预研（TB-006，部分完成）
\end{itemize}

另有 2 个活跃变更尚未归档：首页 UI 精细化、翻译器 UI 精细化、陪练场构建、急救呼吸构建。

\section{当前阻塞与待完善项}

\subsection{后端 BFF 剩余工作}

TB-006 任务书的后端 BFF 层虽已具备主要路由骨架，但以下子任务仍处于待完成状态：

\begin{itemize}
  \item 部分后端仓库层测试尚未补齐（simulation-repository、session-repository 的测试覆盖较薄）。
  \item OpenAPI 文档（\texttt{docs/backtend/openapi.yaml}）需要与当前实际路由保持一致并重新校验。
  \item 多实例部署时的 Redis 级限流尚未接入，当前限流为单机内存实现。
\end{itemize}

\subsection{移动端与可访问性}

\begin{itemize}
  \item 呼吸页的移动端人工验收尚未完成（TB-004 子任务 6）。
  \item 部分页面的 \texttt{prefers-reduced-motion} 降级策略已配置，但尚未经过系统性测试。
\end{itemize}

\subsection{功能缺口}

\begin{itemize}
  \item \texttt{panic\_sessions} 表已创建迁移，但尚未在运行时接入急救呼吸流程的自动记录。
  \item 用户活跃度统计（\texttt{user\_activity\_stats}）表已定义，但数据写入逻辑尚未完整实现。
  \item 关系档案的"长期洞察"与"策略适配"能力处于数据层就绪、分析层待建状态。
\end{itemize}
