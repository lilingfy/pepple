# Pebble AI 技术架构设计文档

## 1. 架构概述

### 1.1 架构目标
- **可维护性**: 模块化设计，职责分离
- **可扩展性**: 支持新功能快速迭代
- **性能**: 首屏加载 < 2s，动画流畅 60fps
- **类型安全**: TypeScript 严格模式

### 1.2 技术选型理由

| 技术 | 选择理由 |
|-----|---------|
| Next.js 15 | App Router、Server Components、内置优化 |
| TypeScript | 类型安全、IDE支持、可维护性 |
| Tailwind CSS | 原子化CSS、设计系统一致、构建优化 |
| Framer Motion | React声明式动画、手势支持、性能优化 |
| Zustand | 轻量、TypeScript友好、无Provider嵌套 |
| shadcn/ui | 无障碍支持、可定制、源码可修改 |

## 3. 状态管理架构

### 3.1 Store设计

```typescript
// store/index.ts
interface AppState
  extends ChatSlice,
          BreathingSlice,
          UserSlice {}

export const useAppStore = create<AppState>()(
  immer(
    devtools(
      persist(
        (...args) => ({
          ...createChatSlice(...args),
          ...createBreathingSlice(...args),
          ...createUserSlice(...args),
        }),
        { name: 'pebble-storage' }
      )
    )
  )
);
```

## 5. 动画架构

### 5.1 动画分类

| 类型 | 实现方式 | 使用场景 |
|-----|---------|---------|
| 呼吸动画 | Framer Motion + CSS Keyframes | 4-7-8呼吸周期 |
| 浮动背景 | Framer Motion animate | 背景装饰 |
| 页面过渡 | Framer Motion AnimatePresence | 路由切换 |
| 微交互 | Tailwind transition | hover/active |
| 滚动动画 | Framer Motion useScroll | 滚动触发 |

### 5.2 呼吸动画时序

```
总周期: 19秒
├── 吸气: 0-4秒 (21%) - scale: 1 → 1.5
├── 屏息: 4-11秒 (37%) - scale: 1.5 (保持)
└── 呼气: 11-19秒 (42%) - scale: 1.5 → 1
```

## 7. API设计

### 7.1 接口列表

| 方法 | 路径 | 描述 |
|-----|------|-----|
| POST | `/api/analyze` | 分析文本情绪潜台词 |
| POST | `/api/chat` | 陪练场AI对话 |
| GET | `/api/scenarios` | 获取场景列表 |

### 7.2 请求/响应格式

```typescript
// POST /api/analyze
interface AnalyzeRequest {
  text: string;
  context?: string;
}

interface AnalyzeResponse {
  surfaceMeaning: string;    // 表面语义
  subtext: string;           // 潜台词
  emotionType: string;       // 情绪类型
  suggestions: Suggestion[]; // 灰岩回复建议
}

interface Suggestion {
  id: string;
  label: string;      // 方案A/B/C
  content: string;    // 回复内容
  strategy: string;   // 策略说明
}
```

## 8. 性能优化策略

### 8.1 构建优化
- 使用 Next.js Image 组件优化图片
- 字体使用 @fontsource 本地加载
- 组件懒加载 (dynamic import)

### 8.2 运行时优化
- 动画使用 transform/opacity (GPU加速)
- 使用 will-change 提示浏览器
- 减少重排重绘

### 8.3 状态优化
- Zustand selector 精确订阅
- 使用 React.memo 避免不必要渲染
- 大数据使用虚拟列表

## 9. 开发规范

### 9.1 代码规范
- TypeScript 严格模式
- ESLint + Prettier 代码格式化
- 组件文件不超过 200 行

### 9.2 命名规范
- 组件: PascalCase
- Hooks: camelCase (use*)
- 工具函数: camelCase
- 常量: UPPER_SNAKE_CASE
- 类型: PascalCase (Type/Interface)

### 9.3 文件规范
```
ComponentName/
├── index.ts          # 导出
├── ComponentName.tsx # 组件
├── ComponentName.test.tsx # 测试
└── types.ts          # 类型 (如需要)
```
