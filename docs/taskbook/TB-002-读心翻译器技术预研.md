## 2. 需求背景

### 2.1 产品定位
读心翻译器是 Pebble AI 的核心功能之一，帮助用户：
- 解析令人不安的言语背后的操控意图
- 识别 Gaslighting、PUA 等情绪操控手段
- 获取不带情绪的"灰岩回复"建议

### 2.2 用户场景
1. 收到让感到压力的信息（如"你怎么这么自私"）
2. 粘贴到输入区，AI分析潜台词
3. 获得情绪中性的回复建议
4. 一键复制或保存到练习本

### 4.3 状态管理

```typescript
// store/slices/translatorSlice.ts

interface TranslatorState {
  inputText: string;
  isAnalyzing: boolean;
  result: AnalysisResult | null;
  history: AnalysisResult[];
}

const useTranslatorStore = create<TranslatorState>((set) => ({
  inputText: '',
  isAnalyzing: false,
  result: null,
  history: [],

  setInputText: (text) => set({ inputText: text }),

  analyze: async (text) => {
    set({ isAnalyzing: true });
    try {
      const response = await fetch('/api/analyze', {
        method: 'POST',
        body: JSON.stringify({ text })
      });
      const result = await response.json();
      set({ result, isAnalyzing: false });
    } catch (error) {
      set({ isAnalyzing: false });
      throw error;
    }
  },

  clearResult: () => set({ result: null }),
  addToHistory: (result) => set((state) => ({
    history: [result, ...state.history]
  }))
}));
```
