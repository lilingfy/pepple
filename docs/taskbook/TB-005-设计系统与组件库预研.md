## 2. 需求背景

### 2.1 业务需求
Pebble AI 是一款基于"灰岩法"的情绪防御助手，需要构建独特的视觉设计系统：
- **极简禅意风格**: 营造宁静、安全的情绪氛围
- **有机鹅卵石形状**: 品牌核心视觉元素
- **玻璃拟态效果**: 现代、轻盈的界面质感
- **呼吸动画**: 核心交互体验

### 2.2 技术需求
- 建立可复用的设计令牌（Design Tokens）
- 构建鹅卵石主题组件库
- 实现一致的动画系统
- 确保响应式和可访问性

## 3. 预研目标

### 3.1 总体目标
建立完整的设计系统，支持四个核心功能模块的UI开发。

### 3.2 具体目标（SMART）

| 目标 | 指标 | 验收标准 |
|------|------|---------|
| **S**pecific | 设计令牌 | 颜色、字体、间距、圆角系统完整定义 |
| **M**easurable | 组件覆盖 | 至少10个鹅卵石主题基础组件 |
| **A**chievable | 动画系统 | 呼吸动画、浮动背景、过渡动画实现 |
| **R**elevant | 一致性 | 所有页面视觉风格统一 |
| **T**ime-bound | 工期 | 5个工作日内完成 |

### 5.2 PebbleShape 组件设计

```typescript
interface PebbleShapeProps {
  children: React.ReactNode;
  variant?: 'soft' | 'medium' | 'hard';  // 形状变异程度
  size?: 'sm' | 'md' | 'lg' | 'xl';
  animate?: boolean;  // 是否启用轻微形变动画
  className?: string;
}
```

**实现要点**:
- 使用 CSS `border-radius` 实现有机形状
- 支持随机种子生成不同变体
- 可选的呼吸式形变动画

### 5.3 GlassCard 组件设计

```typescript
interface GlassCardProps {
  children: React.ReactNode;
  radius?: 'pebble1' | 'pebble2' | 'pebble3' | 'md' | 'lg';
  blur?: 'sm' | 'md' | 'lg' | 'xl';
  opacity?: number;  // 0-1
  border?: boolean;
  shadow?: boolean;
  className?: string;
}
```

**实现要点**:
- `backdrop-filter: blur()` 实现毛玻璃
- 半透明背景色
- 细边框增强边界感
- 可选阴影层次

### 5.4 PebbleButton 组件设计

```typescript
interface PebbleButtonProps extends React.ButtonHTMLAttributes<HTMLButtonElement> {
  variant?: 'primary' | 'secondary' | 'ghost';
  size?: 'sm' | 'md' | 'lg';
  isAnimated?: boolean;  // 呼吸动画
  shape?: 'pebble' | 'rounded';
}
```

**实现要点**:
- 鹅卵石形状或圆角
- hover时轻微放大+阴影
- 点击时缩放反馈
- 可选呼吸动画效果
