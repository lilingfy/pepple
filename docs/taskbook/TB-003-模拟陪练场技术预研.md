## 2. 需求背景

### 2.1 产品定位
模拟陪练场是 Pebble AI 的沉浸式练习功能：
- 在真实冲突发生前进行安全模拟
- AI扮演各种"压力源"角色（同事、伴侣、杠精）
- 实时分析用户回复的情绪中性度
- 提供专业的灰岩应对技巧

### 2.2 用户场景
1. 选择场景（职场越界/亲密关系/社交应对）
2. AI扮演对方发起对话
3. 用户输入回复
4. 系统实时分析情绪得分
5. 提供改进建议

## 3. 功能需求

### 3.2 详细功能

#### 3.2.1 左侧边栏 - 场景选择（ScenarioPanel）

**区块1: 场景选择**
- 三个场景标签：职场越界、亲密关系、社交应对
- 当前场景高亮显示
- 点击切换场景

**数据结构**:
```typescript

  id: string;

  description: string;

const scenarios: Scenario[] = [

```

**区块2: 心理语境**
- 当前情境描述
- 达成目标提示

**示例**:
```
情境：职场越界
一位资深同事试图让你在周末无偿加班，并带有道德绑架。你需要温和但坚定地拒绝。

达成目标：维持职业边界，不JADE（辩解、辩论、解释）。
```

**区块3: 技巧锦囊**
- 当前场景适用的技巧列表
- 每项：圆点标记 + 技巧名称 + 说明

**示例技巧**:
```
• 灰岩法 (Gray Rock): 像灰岩一样平平无奇，不提供情感刺激。

• 肯定+否定: "我很理解项目的紧迫性，但我这周末已有安排，无法协助。"
```

#### 3.2.2 中央聊天区（ChatArea）

**视觉要求**:
- 玻璃拟态背景
- 消息气泡：AI左侧，用户右侧
- 鹅卵石形状头像
- 自定义滚动条

**消息结构**:
```typescript
interface Message {
  id: string;
  role: 'assistant' | 'user';
  content: string;
  timestamp: Date;
  emotionScore?: number;  // 用户消息的情绪得分
}
```

**消息气泡样式**:

| 角色 | 位置 | 背景色 | 圆角 |
|------|------|--------|------|
| AI | 左侧 | slate-200/80 | 0.5rem 2rem 2.5rem 2rem |
| 用户 | 右侧 | moss-green/60 | 2rem 0.5rem 2rem 2.5rem |

**输入区**:
- 圆角输入框
- 发送按钮：鹅卵石形状
- 底部工具栏：语音输入、重启

#### 3.2.3 右侧边栏 - 实时情绪分析（CoachingPanel）

**区块1: 情绪得分圆环**

**视觉要求**:
- 圆形进度条
- 中心显示得分（0-100）
- 进度条颜色随分数变化

**得分等级**:
| 分数 | 等级 | 颜色 |
|------|------|------|
| 80-100 | 优秀 | 安全绿 |
| 60-79 | 良好 | 黄色 |
| 40-59 | 一般 | 橙色 |
| 0-39 | 需改进 | 红色 |

**动画**:
- 得分变化时圆环动画过渡
- 呼吸式光晕效果

**区块2: 得分标签**
- 标签："中性度得分: {等级}"
- 评语：根据得分动态生成

**示例评语**:
```
优秀: "你成功识别了情绪陷阱。当前语气非常克制，有效避免了对抗性升级。"
良好: "整体表现不错，但可以更简洁，减少解释。"
一般: "注意对方在试图激怒你，保持冷静。"
```

**区块3: 陪练建议**

**即时反馈**:
- 分析用户上一条回复
- 指出做得好的地方

**注意点**:
- 预警潜在的情绪陷阱
- 提示应对策略

**示例**:
```
┌─ 即时反馈 ─┐
"我时间已规划好" —— 简洁有力，
未陷入"解释"陷阱。保持住！

┌─ 注意点 ─┐
对方可能在试图激怒你，观察他的
辞藻，不要被"团队精神"四个字带节奏。
```

**结束演练按钮**:
- 底部全宽按钮
- 鹅卵石圆角
- 图标：flag

### 4.2 状态管理

```typescript
// store/slices/chatSlice.ts

interface ChatState {
  // 场景
  currentScenario: Scenario | null;
  scenarios: Scenario[];

  // 消息
  messages: Message[];
  isTyping: boolean;

  // 情绪分析
  emotionScore: number;
  emotionHistory: number[];

  // 会话
  sessionId: string | null;
  startTime: Date | null;
}

const useChatStore = create<ChatState>((set, get) => ({
  currentScenario: null,
  scenarios: [],
  messages: [],
  isTyping: false,
  emotionScore: 85,
  emotionHistory: [],

  sessionId: null,
  startTime: null,

  // 选择场景
  selectScenario: (scenario) => {
    set({
      currentScenario: scenario,
      messages: [],
      sessionId: generateSessionId(),
      startTime: new Date()
    });
    // 加载场景后自动发送开场白
    get().loadScenarioOpening(scenario);
  },

  // 发送消息
  sendMessage: async (content) => {
    const userMessage: Message = {
      id: generateId(),
      role: 'user',
      content,
      timestamp: new Date()
    };

    set((state) => ({
      messages: [...state.messages, userMessage],
      isTyping: true
    }));

    // 分析情绪
    const score = await analyzeEmotion(content);
    set((state) => ({
      emotionScore: score,
      emotionHistory: [...state.emotionHistory, score]
    }));

    // 获取AI回复
    const aiResponse = await getAIResponse(content, get().messages);
    set((state) => ({
      messages: [...state.messages, {
        id: generateId(),
        role: 'assistant',
        content: aiResponse,
        timestamp: new Date()
      }],
      isTyping: false
    }));
  },

  // 重置会话
  resetSession: () => set({
    messages: [],
    emotionScore: 85,
    emotionHistory: []
  })
}));
```

#### 情绪得分圆环

```typescript
// components/dojo/EmotionScore.tsx
"use client";

import { motion } from "framer-motion";

interface EmotionScoreProps {
  score: number;
}

export function EmotionScore({ score }: EmotionScoreProps) {
  // 根据分数确定颜色和等级
  const getScoreConfig = (score: number) => {
    if (score >= 80) return { color: '#A8D8B9', label: '优秀' };
    if (score >= 60) return { color: '#FCD34D', label: '良好' };
    if (score >= 40) return { color: '#FB923C', label: '一般' };
    return { color: '#F87171', label: '需改进' };
  };

  const config = getScoreConfig(score);
  const circumference = 2 * Math.PI * 50; // 半径50
  const strokeDashoffset = circumference - (score / 100) * circumference;

  return (
    <div className="glass-card p-8 rounded-pebble-3 flex flex-col items-center text-center relative overflow-hidden">
      {/* 装饰光晕 */}
      <div className="absolute -top-10 -right-10 w-24 h-24 bg-yellow-200/30 blur-3xl rounded-full" />

      <h3 className="font-bold text-slate-700 mb-6 tracking-wider flex items-center gap-2">
        <span className="material-symbols-outlined text-pebble-healing animate-pulse">
          insights
        </span>
        实时情绪分析
      </h3>

      {/* 圆环 */}
      <div className="relative w-36 h-36 flex items-center justify-center mb-6">
        {/* 外发光 */}
        <div
          className="absolute inset-0 rounded-full blur-xl animate-pulse"
          style={{ background: `${config.color}33` }}
        />

        {/* 背景圆环 */}
        <div className="absolute inset-0 rounded-full border-[6px] border-white/50" />

        {/* 进度圆环 */}
        <svg className="absolute inset-0 w-full h-full -rotate-90">
          <circle
            cx="72"
            cy="72"
            r="50"
            fill="none"
            stroke={config.color}
            strokeWidth="6"
            strokeLinecap="round"
            strokeDasharray={circumference}
            strokeDashoffset={strokeDashoffset}
            className="transition-all duration-1000 ease-out"
          />
        </svg>

        {/* 中心得分 */}
        <div className="w-28 h-28 rounded-full bg-white/90 flex flex-col items-center justify-center shadow-inner">
          <span
            className="text-4xl font-bold"
            style={{ color: config.color }}
          >
            {score}
          </span>
          <span className="text-[10px] text-slate-400 uppercase tracking-widest font-bold">
            SCORE
          </span>
        </div>
      </div>

      {/* 等级标签 */}
      <div
        className="px-4 py-1.5 rounded-full mb-3"
        style={{ background: `${config.color}1A` }}
      >
        <p
          className="text-sm font-bold"
          style={{ color: config.color }}
        >
          中性度得分: {config.label}
        </p>
      </div>

      {/* 评语 */}
      <p className="text-xs text-slate-600/80 leading-relaxed max-w-[200px]">
        {getFeedbackText(score)}
      </p>
    </div>
  );
}

function getFeedbackText(score: number): string {
  if (score >= 80) {
    return '你成功识别了情绪陷阱。当前语气非常克制，有效避免了对抗性升级。';
  }
  if (score >= 60) {
    return '整体表现不错，但可以更简洁，减少解释。';
  }
  if (score >= 40) {
    return '注意对方在试图激怒你，保持冷静。';
  }
  return '深呼吸，尝试使用更中性、更简短的回复。';
}
```

### 4.4 API设计

```typescript
// app/api/chat/route.ts

interface ChatRequest {
  message: string;
  history: Message[];
  scenarioId: string;
}

interface ChatResponse {
  response: string;
  emotionAnalysis: {
    score: number;
    feedback: string;
  };
}

export async function POST(request: Request) {
  const { message, history, scenarioId } = await request.json();

  // 情绪分析
  const emotionScore = await analyzeEmotion(message);

  // 生成AI回复
  const aiResponse = await generateAIResponse({
    message,
    history,
    scenario: getScenarioById(scenarioId)
  });

  return Response.json({
    response: aiResponse,
    emotionAnalysis: {
      score: emotionScore,
      feedback: generateFeedback(emotionScore)
    }
  });
}
```
