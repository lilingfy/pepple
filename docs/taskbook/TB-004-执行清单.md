# TB-004 急救呼吸技术预研执行清单

> 适用对象：呼吸页前端实现、动画控制、计时逻辑与验收

> **实现状态（2026-03-23）**：子任务 1-5 和子任务 7 已完成（build-pebble-breathing 变更）。子任务 6（移动端人工验收）待执行。

## 1. 执行目标

把急救呼吸任务书拆成可直接执行的前端任务，确保页面能完成 4-7-8 呼吸引导、倒计时、沉浸式动效和移动端适配。

## 2. 执行原则

1. 呼吸节奏优先于装饰效果。
2. 动画和计时必须由同一状态源驱动。
3. 页面可离线运行，不依赖后端。
4. 视觉效果要沉浸，但不能制造眩晕或阅读负担。
5. 必须处理暂停、重置和重复进入页面的稳定性。
