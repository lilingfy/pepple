# TB-001 首页模块技术预研执行清单

> 适用对象：首页前端实现、组件开发、交互与验收

## 1. 执行目标

把首页任务书拆成可直接执行的前端任务，确保首页能够按照设计稿落地到 Next.js 页面，完成导航、Hero、统计卡片、功能入口和基础动效。

## 2. 执行原则

1. 先写组件测试或页面行为测试，再写实现。
2. 先搭路由壳和布局，再补视觉细节。
3. 优先复用 `TB-005` 的设计系统组件。
4. 动效服务于信息传达，不能影响首屏可读性。
5. 首页文案、跳转和 CTA 必须与后续功能页保持一致。

## 3. 子任务拆解

### 子任务 1: 首页路由和页面骨架

**目标**
- 搭建首页路由和基本布局
- 明确导航、主体内容、页脚的页面结构

**建议文件**
- 修改 `apps/web/app/page.tsx`
- 新增 `apps/web/components/home/HomePage.tsx`
- 新增 `apps/web/tests/frontend/home-page.test.tsx`

**交付物**
- 首页主路由
- 页面主容器
- 基础 SEO 元信息

**验收点**
- 访问 `/` 能渲染首页
- 页面结构与任务书区块划分一致

---

### 子任务 2: 顶部导航和页脚

**目标**
- 实现固定导航、Logo、导航菜单和页脚
- 保证跳转路径和高亮状态正确

**建议文件**
- 新增 `apps/web/components/home/Navigation.tsx`
- 新增 `apps/web/components/home/Footer.tsx`
- 修改 `apps/web/components/layout/*`

**交付物**
- 固定导航
- 当前页面高亮
- 首页到功能页的可用跳转
- 页脚版权和隐私入口
- 优先复用 `MainHeader` 与 `PageShell`

**验收点**
- 导航在桌面端和移动端都可用
- 功能入口链接与任务书定义的路由一致

---

### 子任务 3: Hero 主视觉区

**目标**
- 实现标题、副标题、背景漂浮元素和 CTA 按钮
- 还原“情绪盔甲”主视觉层次

**建议文件**
- 新增 `apps/web/components/home/HeroSection.tsx`
- 新增 `apps/web/components/home/CoreArmorText.tsx`
- 新增 `apps/web/components/home/AmbientBackground.tsx`

**交付物**
- 主标题和副标题
- `CoreArmorText` 特效
- 主 CTA 与次 CTA
- 首屏动效
- CTA 优先复用 `PebbleButton`

**验收点**
- 首屏在桌面和移动端都可读
- 标题层级、按钮层级和背景层级清晰

---

### 子任务 4: 统计区

**目标**
- 实现四项统计卡片和进入视口动画
- 展示品牌可信度与产品价值

**建议文件**
- 新增 `apps/web/components/home/StatsSection.tsx`
- 新增 `apps/web/components/home/StatItem.tsx`

**交付物**
- 四个数据项
- 分隔线和玻璃卡片容器
- 数字递增动效
- 统计容器优先复用 `GlassCard`

**验收点**
- 数据文案准确
- 视觉节奏与 Hero 区衔接自然

---

### 子任务 5: 功能预览区

**目标**
- 实现三张核心功能卡片
- 提供到翻译器、陪练场、急救呼吸的入口

**建议文件**
- 新增 `apps/web/components/home/FeatureSection.tsx`
- 新增 `apps/web/components/home/FeatureCard.tsx`

**交付物**
- 三张功能卡片
- 图标与描述
- hover 动效
- 点击跳转

**验收点**
- 三张卡片的信息密度均衡
- 交互不会误导用户进入错误页面

---

### 子任务 6: 响应式与可访问性

**目标**
- 保证首页在移动端、平板和桌面端都可用
- 处理键盘焦点、语义标签和按钮可点击区域

**建议文件**
- 修改 `apps/web/components/home/*`
- 新增或修改样式与测试文件

**交付物**
- 响应式断点适配
- 键盘导航可用
- 合理的标题语义和按钮语义

**验收点**
- 主要功能可通过键盘完成
- 移动端没有横向溢出

---

### 子任务 7: 测试与回归

**目标**
- 为首页关键区块建立稳定回归测试
- 锁定路由、文案、跳转和主交互

**建议文件**
- 新增 `apps/web/tests/frontend/home-page.test.tsx`
- 必要时新增 `apps/web/tests/e2e/home.spec.ts`

**交付物**
- 首页渲染测试
- CTA 跳转测试
- 导航状态测试

**验收点**
- 修改样式或组件拆分后，核心行为仍可回归验证

## 4. 推荐执行顺序

1. 子任务 1，先建立首页路由和页面骨架。
2. 子任务 2，接入导航和页脚。
3. 子任务 3，完成 Hero 主视觉。
4. 子任务 4，完成统计区。
5. 子任务 5，完成功能预览区。
6. 子任务 6，统一处理响应式和可访问性。
7. 子任务 7，补齐回归测试。

## 5. 逐项完成标准

- 页面结构和视觉层次与任务书一致。
- 功能入口可用且路径正确。
- 动效、响应式和测试都具备基本交付标准。
