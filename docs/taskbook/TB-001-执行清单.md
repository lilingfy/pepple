# TB-001 首页模块技术预研执行清单

> 适用对象：首页前端实现、组件开发、交互与验收

## 1. 执行目标

把首页任务书拆成可直接执行的前端任务，确保首页能够按照设计稿落地到 Next.js 页面，完成导航、Hero、统计卡片、功能入口和基础动效。

## 2. 执行原则

1. 先写组件测试或页面行为测试，再写实现。
2. 先搭路由壳和布局，再补视觉细节。
3. 优先复用 `TB-005` 的设计系统组件。
4. 动效服务于信息传达，不能影响首屏可读性。
5. 首页文案、跳转和 CTA 必须与后续功能页保持一致。

### 子任务 9: 滚动触发动画

**目标**
- 实现各区块的滚动触发动画效果
- 区分不同区块的入场动画类型

**建议文件**
- 新增 `apps/web/hooks/useScrollReveal.ts`
- 修改 `apps/web/components/home/*`

**交付物**
- IntersectionObserver 滚动检测 Hook
- 各区块初始隐藏状态（opacity-0）
- practice 和 breathing 区块：pop-out效果（scale-[0.85] → scale-100）
- 其他区块：slide-up效果（translate-y-24 → translate-y-0）
- 动画时长：1200ms

**验收点**
- 滚动到区块时触发动画
- 动画流畅无卡顿
- 离开视口时重置动画状态（可选）
