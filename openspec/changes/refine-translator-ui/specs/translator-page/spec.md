# Incremental Spec: translator-page

> 变更：refine-translator-ui
> 类型：MODIFIED

## MODIFIED Requirements

### 需求: 情绪状态条位置与显示策略

**原行为**：情绪状态条仅在 result 态展示 AI 返回的情绪数据，idle 态隐藏。

**新行为**：情绪状态条常驻显示于输入区下方，默认展示模拟数据（心率 85%），result 态更新为真实分析结果。

#### 场景: 情绪状态条常驻渲染

- **当** 页面处于任意状态
- **那么** 情绪状态条始终可见，位置固定在输入区下方
- **且** idle/analyzing 态显示默认文本 "情绪检测：平稳观察中" 和心率 85%
- **且** result 态更新为 AI 返回的 `emotionStatus` 和 `emotionScore`

---

### 需求: 页面顶部留白间距

**原行为**：页面内容紧贴 Header，无额外顶部留白。

**新行为**：左栏内容区域增加 `mt-28`（7rem）顶部留白。

#### 场景: 左栏顶部留白

- **当** 页面渲染三栏布局
- **那么** 左栏（输入区）和右栏（结果区）均应用 `mt-28` 顶部外边距

---

### 需求: 解码按钮视觉规范

**原行为**：解码按钮使用标准 `rounded-pebble` 圆角。

**新行为**：解码按钮使用精确异形圆角 `rounded-[45%_55%_70%_30%/30%_40%_60%_70%]`，增加光晕和装饰元素。

#### 场景: 解码按钮异形形状

- **当** 解码按钮渲染
- **那么** 应用异形 border-radius：`45% 55% 70% 30% / 30% 40% 60% 70%`
- **且** 尺寸调整为 `w-32 h-32 md:w-40 md:h-40`
- **且** 图标添加黄色光晕：`drop-shadow-[0_0_8px_rgba(255,237,148,0.6)]`

#### 场景: 解码按钮装饰元素

- **当** 解码按钮渲染
- **那么** 包含两个装饰点：
  - 顶部：`absolute -top-4 -right-2 w-4 h-4 bg-[#FFED94]/70` 带 pulse 动画
  - 底部：`absolute -bottom-6 -left-4 w-6 h-6 bg-moss-green` 无动画

---

### 需求: 回复建议卡片交互

**原行为**：回复建议卡片静态展示，无悬停动效。

**新行为**：卡片具有横向位移层级，悬停时复位，边框颜色按优先级区分。

#### 场景: 卡片位移层级

- **当** 回复建议卡片渲染
- **那么** 应用以下 translate-x 值：
  - 方案 A：`translate-x-2`
  - 方案 B：`translate-x-1`
  - 方案 C：`translate-x-2`

#### 场景: 卡片悬停复位

- **当** 用户悬停在任意卡片
- **那么** 该卡片位移复位为 `translate-x-0`

#### 场景: 卡片边框颜色

- **当** 回复建议卡片渲染
- **那么** 左侧边框颜色按方案区分：
  - 方案 A：`border-safe-green`
  - 方案 B：`border-[#FFED94]/80`
  - 方案 C：`border-slate-300`

---

### 需求: Header 导航区扩展

**原行为**：Header 仅包含 Logo 和导航链接。

**新行为**：Header 右侧添加通知图标和用户头像区域。

#### 场景: Header 图标区

- **当** Header 渲染
- **那么** 右侧显示：
  - 通知按钮（`notifications` 图标），带红点角标（`w-2 h-2 bg-rose-400`）
  - 用户头像占位（圆形 `w-10 h-10 bg-primary/20` 带 `person` 图标）

---

### 需求: 标签中英文双语显示

**原行为**：标签仅显示中文，或显示混乱的中英文。

**新行为**：所有标签以中文为主，英文作为副标题放在括号内，使用图标前缀增强视觉识别。

#### 场景: 输入区标签

- **当** 输入区渲染
- **那么** 标签显示为"收到信息 (压力源)"，带图标前缀

#### 场景: 分析结果标签

- **当** 表面语义卡片渲染
- **那么** 标签显示为"表面语义 (Surface Meaning)"，带 hearing 图标
- **当** 潜台词卡片渲染
- **那么** 标签显示为"潜台词 (Subtext)"，带 visibility 图标

#### 场景: 回复建议标签

- **当** 回复建议区域渲染
- **那么** 标签显示为"灰岩回复建议 (Gray Rock Replies)"，带 layers 图标

#### 场景: 按钮标签

- **当** 复制建议按钮渲染
- **那么** 按钮文字显示为"复制建议"（非英文 Copy）
- **当** 存入练习本按钮渲染
- **那么** 按钮文字显示为"存入练习本"（非英文 Save）

---

### 需求: 右侧初始状态显示示例内容

**原行为**：右侧初始状态显示"输入一段让你感到困扰的话"等提示文字。

**新行为**：右侧初始状态显示与设计稿一致的示例内容，包括示例分析结果和回复建议。

#### 场景: 初始状态展示示例内容

- **当** 页面加载且未输入内容时
- **那么** 右侧显示：
  - 表面语义示例卡片："你怎么这么自私，连这点忙都不帮？"
  - 潜台词示例卡片："对方可能正处于焦虑中..."
  - 三个示例回复建议卡片（方案 A/B/C）
  - 底部"复制建议"和"存入练习本"按钮（非禁用状态）

分析结果区底部必须显示"复制建议"和"存入练习本"按钮组。

#### 场景: 复制建议按钮

- **当** 分析结果渲染完成
- **那么** 底部显示"复制建议"按钮：
  - 样式：圆角全满，边框 `border-primary/30`，背景 `bg-white/20`
  - 图标：`content_copy`，hover 变填充状态

#### 场景: 存入练习本按钮

- **当** 分析结果渲染完成
- **那么** 底部显示"存入练习本"按钮：
  - 样式：圆角全满，背景 `bg-primary`，文字白色
  - 图标：`favorite`，hover 变红填充

---

### 需求: SVG 内联图标替换

**原行为**：使用 `material-symbols-outlined` 字体图标，在部分环境下显示为乱码。

**新行为**：所有图标使用内联 SVG，确保跨浏览器兼容性和离线可用性。

#### 场景: Header 图标

- **当** Header 渲染时
- **那么** 通知按钮使用 BellIcon SVG
- **且** 用户头像使用 PersonIcon SVG

#### 场景: 解码按钮图标

- **当** 解码按钮渲染时
- **那么** 使用 SparkleIcon SVG（黄色星星带光晕）

#### 场景: 输入区工具栏图标

- **当** 输入区渲染时
- **那么** 麦克风按钮使用 MicIcon SVG
- **且** 附件按钮使用 AttachFileIcon SVG

#### 场景: 分析结果卡片图标

- **当** 表面语义卡片渲染时
- **那么** 使用 HearingIcon（耳朵形状）
- **当** 潜台词卡片渲染时
- **那么** 使用 VisibilityIcon（眼睛形状）

#### 场景: 回复建议区图标

- **当** 回复建议区域渲染时
- **那么** 标签使用 LayersIcon SVG
- **且** 复制按钮使用 CopyIcon/CheckIcon SVG
- **且** 保存按钮使用 HeartIcon SVG（支持填充状态）

#### 场景: 情绪状态条图标

- **当** 情绪状态条渲染时
- **那么** 心率指示器使用 HeartIcon SVG（玫瑰红色）
