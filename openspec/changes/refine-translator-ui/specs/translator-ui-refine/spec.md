# Capability: translator-ui-refine

## Purpose

定义 Pebble AI 读心翻译器界面 UI 精修规范，对齐第二版设计稿视觉系统，包括标题区重构、异形圆角组件、动效系统和背景装饰元素。

## Requirements

### 需求: 页面标题区视觉结构

页面标题区必须使用 AI 大字 + 竖线分隔 + "读心翻译器" 的组合布局，副标题包含呼吸灯动画指示器。

#### 场景: 标题区渲染

- **当** 页面加载完成
- **那么** 标题区显示：
  - 左侧金色 "AI" 大字号文字（`text-[#BCA564]`，`text-6xl`，`font-black`）
  - 下方横线装饰（`h-[3px] w-10 bg-[#BCA564]/60`）
  - 竖线分隔符（`h-12 w-[1.5px] bg-slate-300/50`）
  - 右侧 "读心翻译器" 标题（`text-3xl`，主色 `#7D8C9F`）
  - 副标题 "Empathic Insight Engine"（`text-xs font-serif italic`）带呼吸灯绿点

### 需求: 输入区异形圆角样式

输入区容器必须使用 `rounded-pebble` 异形圆角（`2rem 3rem 2.5rem 4rem`），应用内阴影（pebble-inset）和玻璃拟态背景。

#### 场景: 输入区容器渲染

- **当** 输入区组件渲染
- **那么** 容器应用以下样式：
  - 圆角：`rounded-[2rem_3rem_2.5rem_4rem]`（CSS 变量 `--radius-pebble`）
  - 背景：`bg-white/60` 或 `bg-white/70`
  - 阴影：内阴影 `inset 6px 6px 12px rgba(125, 140, 159, 0.15), inset -6px -6px 12px rgba(255, 255, 255, 0.8)`

### 需求: 解码按钮异形形状与光晕

解码按钮必须使用精确异形圆角 `rounded-[45%_55%_70%_30%/30%_40%_60%_70%]`，图标添加黄色光晕阴影效果。

#### 场景: 解码按钮渲染

- **当** 解码按钮组件渲染
- **那么** 按钮应用：
  - 形状：`rounded-[45%_55%_70%_30%/30%_40%_60%_70%]`
  - 尺寸：`w-32 h-32 md:w-40 md:h-40`
  - 图标光晕：`drop-shadow-[0_0_8px_rgba(255,237,148,0.6)]`
  - 装饰点：顶部黄点带 pulse 动画，底部绿色鹅卵石形状点

#### 场景: 解码按钮悬停动效

- **当** 用户鼠标悬停在解码按钮
- **那么** 图标旋转 180 度（`group-hover:rotate-180 transition-transform duration-700`）

### 需求: 情绪状态条常驻显示

情绪状态条必须从 result 态条件渲染改为常驻显示，位置固定在输入区下方，展示检测状态和心率模拟值。

#### 场景: 情绪状态条常驻渲染

- **当** 页面处于任意状态（idle/analyzing/result/error）
- **那么** 情绪状态条始终显示在输入区下方，包含：
  - 左侧：绿点 pulse 动画 + "情绪检测：平稳观察中" 文本
  - 中间（桌面端可见）：辅助文本 "频率正常，适合进行理性解码"（`text-xs text-slate-400 italic`）
  - 右侧：心率值（默认 85%）带爱心图标

### 需求: 分析结果卡片异形圆角

表面语义卡片使用 `rounded-pebble`，潜台词卡片使用 `rounded-pebble-alt` 异形圆角。

#### 场景: 分析卡片渲染

- **当** 分析结果渲染
- **那么** 表面语义卡片使用 `rounded-[2rem_3rem_2.5rem_4rem]`
- **且** 潜台词卡片使用 `rounded-[4rem_2rem_3.5rem_2.5rem]`（`--radius-pebble-alt`）

### 需求: 回复建议卡片悬停位移动效

回复建议卡片必须具有横向位移效果，悬停时复位。

#### 场景: 卡片悬停动效

- **当** 页面渲染回复建议卡片
- **那么** 卡片按以下位移层级：
  - 方案 A：`translate-x-2`
  - 方案 B：`translate-x-1`
  - 方案 C：`translate-x-2`
- **且** 悬停时统一复位为 `translate-x-0`
- **且** 每张卡片具有左侧边框颜色区分（A=safe-green，B=黄色带边框，C=灰色）
- **且** 方案 B 标签必须具有边框样式 `border border-[#FFED94]/40`

### 需求: 背景装饰元素

页面必须包含固定定位的鹅卵石形状背景装饰图案。

#### 场景: 背景装饰渲染

- **当** 页面加载
- **那么** 左下角和右上角各渲染一个鹅卵石形状 SVG 装饰：
  - 左下角：绿色（`#A8D8B9`），`opacity-20`，尺寸 200x200
  - 右上角：灰色（`#7D8C9F`），`opacity-10`，尺寸 150x150，旋转 45 度

### 需求: Header 导航栏样式

Header 导航栏必须区分当前页面和非当前页面的视觉样式，当前页使用高亮背景和粗体，非当前页使用细体。

#### 场景: 当前页导航项高亮

- **当** 用户位于读心翻译器页面（/translator）
- **那么** "读心翻译" 导航项显示为：
  - 背景：`bg-[#A8D8B9]/20`
  - 字体：`font-bold` / `font-[700]`
  - 文字颜色：`text-[#2C3E50]`
  - 底部指示点：绿色圆点带 pulse 动画
- **且** 其他导航项（首页、模拟陪练、急救呼吸）显示为：
  - 字体：`font-light`
  - 文字颜色：`text-[#7D8C9F]`
  - hover 状态：`hover:bg-[#A8D8B9]/20 hover:text-[#2C3E50] hover:font-bold`

### 需求: Header 导航图标区

Header 必须包含通知图标（带红点）和用户头像下拉区域。

#### 场景: Header 图标区渲染

- **当** Header 组件渲染
- **那么** 右侧显示：
  - 通知图标（`notifications` Material Symbol），带红点角标
  - 用户头像占位（圆形 `bg-primary/20` 带 `person` 图标）

### 需求: 底部操作按钮组

分析结果区底部必须显示"复制建议"和"存入练习本"按钮组。

#### 场景: 底部按钮渲染

- **当** 分析结果区渲染完成
- **那么** 底部显示两个按钮：
  - 复制建议：圆角全满，边框样式，带 `content_copy` 图标
  - 存入练习本：主色填充背景，带 `favorite` 图标，hover 变红填充
