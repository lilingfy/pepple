## MODIFIED Requirements

### 需求:首页 Navigation 组件必须符合设计稿视觉规范
首页顶部导航必须使用异形鹅卵石 Logo，并在当前页导航项显示脉冲点指示器。

#### 场景:Logo 显示为异形鹅卵石形状
- **当** 用户浏览首页
- **那么** Logo 图标必须使用异形圆角：rounded-[60%_40%_70%_30%/_40%_50%_60%_40%]
- **并且** Logo 必须有 hover 状态：背景色变为品牌绿色，并旋转 12 度、放大 1.1 倍

#### 场景:当前页导航显示脉冲指示器
- **当** 用户位于首页
- **那么** "首页"导航项必须有底部脉冲点（w-1.5 h-1.5 rounded-full）
- **并且** 脉冲点必须使用品牌绿色并带有 animate-pulse 动画

### 需求:首页 HeroSection 必须包含滚动指示器和正确 CTA 按钮
首页 Hero 区块底部必须显示滚动指示动画线条，CTA 按钮组必须包含"立即体验"和"演示视频"。

#### 场景:Hero 底部显示滚动指示器
- **当** 用户浏览首页首屏
- **那么** Hero 区块底部中央必须显示一条垂直动画线条
- **并且** 线条必须有从上往下生长的动画效果，提示用户向下滚动

#### 场景:CTA 按钮组符合设计稿
- **当** 用户查看 Hero 区域
- **那么** 必须显示两个按钮："立即体验"（主按钮样式）和"演示视频"（次按钮样式，带播放图标）
- **并且** "立即体验"按钮必须链接到 /translator
- **并且** "演示视频"按钮必须链接到 /demo（占位，可后续实现）

### 需求:首页 StatsSection 必须显示脉冲绿点装饰
首页统计区每个数字前必须显示脉冲绿点，数字本身必须有发光阴影效果。

#### 场景:统计数字前显示脉冲绿点
- **当** 用户查看统计区
- **那么** 每个统计数字前必须有一个 w-2 h-2 的圆点
- **并且** 圆点必须使用品牌绿色（#A8D8B9）
- **并且** 圆点必须有发光阴影（box-shadow: 0 0 8px rgba(168,216,185,0.8)）
- **并且** 圆点必须有 animate-pulse 动画

#### 场景:统计数字有 hover 效果
- **当** 用户鼠标悬停在统计项上
- **那么** 脉冲绿点必须放大到 1.5 倍
- **并且** 数字颜色必须从品牌主色过渡到文本色

### 需求:首页 DecoderSection 读心翻译器展示区块必须符合设计稿
首页必须包含读心翻译器独立展示区块，包含左侧功能介绍和右侧 DecoderDemo 演示卡片。

#### 场景:DecoderSection 显示左侧功能介绍
- **当** 用户浏览首页读心翻译器区块
- **那么** 左侧必须显示英文标签 "MIND-READING TRANSLATOR"
- **并且** 必须显示主标题 "AI 读心翻译器"
- **并且** 必须显示功能描述和特性列表（识别操控、获取灰岩回复策略）

#### 场景:DecoderSection 显示右侧演示卡片
- **当** 用户浏览首页读心翻译器区块
- **那么** 右侧必须显示 DecoderDemo 交互式演示卡片
- **并且** 演示卡片必须包含示例输入、潜台词分析、灰岩回复建议

#### 场景:DecoderSection 顶部装饰
- **当** 用户浏览首页读心翻译器区块
- **那么** 区块顶部必须显示双向箭头装饰和脉冲圆点
- **并且** 区块背景必须为品牌背景色，顶部圆角（rounded-t-[4rem]）

### 需求:首页 PracticeSection 模拟陪练场展示区块必须符合设计稿
首页必须包含模拟陪练场独立展示区块，包含居中标题区和三张场景卡片。

#### 场景:PracticeSection 显示标题区
- **当** 用户浏览首页模拟陪练场区块
- **那么** 必须显示英文标签 "PRACTICE DOJO"
- **并且** 必须显示主标题 "模拟陪练场"
- **并且** 必须显示副标题 "在真实冲突发生前，通过安全的模拟接种心理疫苗"

#### 场景:PracticeSection 显示三张场景卡片
- **当** 用户浏览首页模拟陪练场区块
- **那么** 必须显示三张场景卡片：职场越界防御、亲密关系解绑、社交杠精应对
- **并且** 每张卡片必须包含：渐变背景、图标、标题、描述、开始演练按钮
- **并且** "社交杠精应对"卡片右上角必须显示"最常练习"标签

#### 场景:PracticeSection 卡片交互
- **当** 用户鼠标悬停在场景卡片上
- **那么** 卡片必须上浮（translate-y-2）
- **并且** 阴影必须增强
- **并且** 图标容器必须变色

### 需求:首页 BreathingSection 急救呼吸展示区块必须符合设计稿
首页必须包含急救呼吸独立展示区块，包含居中标题区和大尺寸呼吸鹅卵石。

#### 场景:BreathingSection 显示标题区
- **当** 用户浏览首页急救呼吸区块
- **那么** 必须显示英文标签 "EMERGENCY BREATHING"
- **并且** 必须显示主标题 "急救呼吸"
- **并且** 必须显示副标题 "情绪淹没时，请点击下方，跟随鹅卵石的律动找回平静"

#### 场景:BreathingSection 显示呼吸鹅卵石
- **当** 用户浏览首页急救呼吸区块
- **那么** 必须显示大尺寸呼吸鹅卵石（288px）
- **并且** 鹅卵石必须使用渐变背景（#B5E2C5 → #9BCBAE）
- **并且** 必须包含风图标和"急救呼吸"文字

#### 场景:页脚 Logo 使用异形鹅卵石
- **当** 用户查看页脚
- **那么** Logo 必须使用与设计稿一致的异形圆角形状
- **并且** Logo 尺寸必须为 w-4 h-4
