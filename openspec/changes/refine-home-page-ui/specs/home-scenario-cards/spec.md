## ADDED Requirements

### 需求:模拟陪练场 ScenarioCard 组件必须展示场景信息
模拟陪练场展示区块必须包含三张场景卡片，每张卡片展示一个练习场景的入口信息。

#### 场景:ScenarioCard 显示场景基本信息
- **当** 用户浏览首页模拟陪练场区块
- **那么** 每张场景卡片必须显示：图标、标题、描述、开始演练按钮
- **并且** 图标容器必须为圆角方形（rounded-2xl），尺寸为 64×64px

#### 场景:ScenarioCard 显示渐变背景
- **当** 用户查看场景卡片
- **那么** "职场越界防御"卡片必须使用灰绿渐变背景（#F0F6F2 → #E6ECE8）
- **并且** "亲密关系解绑"卡片必须使用灰橙渐变背景（#F0F6F2 → #F2EBE6）
- **并且** "社交杠精应对"卡片必须使用安全绿高亮背景（#F0F6F2 + 内发光）

#### 场景:ScenarioCard 显示最常练习标签
- **当** 用户查看"社交杠精应对"卡片
- **那么** 卡片右上角必须显示"最常练习"标签
- **并且** 标签背景为品牌绿色半透明（bg-brand-safe/20）
- **并且** 标签文字为品牌绿色

#### 场景:ScenarioCard hover 效果
- **当** 用户鼠标悬停在场景卡片上
- **那么** 卡片必须上浮（-translate-y-2）
- **并且** 阴影必须增强（hover:shadow-2xl）
- **并且** 图标容器背景色必须变化（对应卡片的强调色）
- **并且** 图标颜色必须变为白色

#### 场景:ScenarioCard 响应式布局
- **当** 用户在桌面端查看
- **那么** 三张卡片必须横向三列排列
- **当** 用户在移动端查看
- **那么** 三张卡片必须垂直单列排列
