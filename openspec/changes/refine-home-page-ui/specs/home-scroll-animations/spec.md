## ADDED Requirements

### 需求:首页区块必须使用 IntersectionObserver 实现滚动渐显动画
首页各内容区块（Hero 除外）必须在进入视口时触发渐显动画，动画效果分为 slide-up（上移渐显）和 pop-out（缩放弹出）两种类型，且必须支持减少动画偏好退化。

#### 场景:区块进入视口时触发 slide-up 动画
- **当** 用户向下滚动页面，统计区或功能预览区进入视口 15% 以上
- **那么** 区块必须从下方 24px 位置以 opacity 0→1、translateY 24px→0、scale 0.95→1 的动画渐显
- **并且** 动画持续时间必须为 1200ms，缓动函数为 ease-out

#### 场景:区块进入视口时触发 pop-out 动画
- **当** 用户向下滚动页面，陪练场或急救呼吸区进入视口 15% 以上
- **那么** 区块必须以 opacity 0→1、scale 0.85→1 的动画弹出显示
- **并且** 动画持续时间必须为 1200ms，缓动函数为 ease-out

#### 场景:减少动画偏好下动画退化
- **当** 用户系统启用 prefers-reduced-motion: reduce
- **那么** 所有滚动渐显动画必须禁用，区块直接以最终状态显示

#### 场景:区块离开视口时重置状态
- **当** 用户向上滚动，区块完全离开视口
- **那么** 区块必须重置为初始隐藏状态，以便再次进入时重新触发动画
