## ADDED Requirements

### 需求:读心翻译器 DecoderDemo 组件必须展示产品核心能力
读心翻译器功能预览区必须展示一个完整的交互式演示组件，包含示例输入、解码结果和回复建议，使用静态数据展示产品能力。

#### 场景:DecoderDemo 展示示例对话
- **当** 用户浏览首页读心翻译器区块
- **那么** 系统必须展示一个示例输入卡片，内容为"对方发来：你连这点小事都做不好，离开我你还能干什么？"
- **并且** 示例卡片必须有圆角、阴影和边框样式

#### 场景:DecoderDemo 展示解码结果
- **当** 用户查看 DecoderDemo
- **那么** 系统必须展示解码结果区域，包含"潜台词"标签和解析文本"我需要通过贬低你来证明我的价值并控制你。（投射与情感勒索）"
- **并且** 解码结果区域必须有品牌色边框和背景

#### 场景:DecoderDemo 展示回复建议
- **当** 用户查看 DecoderDemo
- **那么** 系统必须展示"灰岩回复建议"标签和两个可点击建议按钮："极简：嗯。"和"温和：那是你的看法。"
- **并且** 建议按钮必须有 hover 状态反馈

#### 场景:DecoderDemo 响应式适配
- **当** 用户在移动端查看首页
- **那么** DecoderDemo 必须垂直堆叠显示，确保内容可读性
- **并且** 输入卡片和解码结果卡片宽度必须自适应屏幕
