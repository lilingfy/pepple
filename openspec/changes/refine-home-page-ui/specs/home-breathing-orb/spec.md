## ADDED Requirements

### 需求:急救呼吸区块必须展示交互式鹅卵石呼吸动画
急救呼吸功能预览区必须展示一个可交互的鹅卵石形状动画组件，包含基础呼吸动画和 hover 时的波纹扩散效果。

#### 场景:展示基础呼吸鹅卵石
- **当** 用户浏览首页急救呼吸区块
- **那么** 系统必须展示一个异形鹅卵石形状的核心按钮，尺寸为 192×192px
- **并且** 鹅卵石必须使用渐变背景色（从 #B5E2C5 到 #9BCBAE）
- **并且** 鹅卵石必须有柔和阴影（shadow-xl）

#### 场景:基础呼吸动画自动播放
- **当** 页面加载完成
- **那么** 鹅卵石必须自动播放呼吸动画：scale 1→1.05→1，opacity 0.8→0.6→0.8
- **并且** 动画周期必须为 8s，无限循环
- **并且** 动画缓动函数必须为 ease-in-out

#### 场景:hover 时触发波纹扩散动画
- **当** 用户鼠标悬停在呼吸鹅卵石上
- **那么** 必须从鹅卵石中心向外扩散三层波纹
- **并且** 每层波纹必须有不同的动画延迟（0s、1.3s、2.6s）
- **并且** 波纹动画周期为 4s，scale 从 0.9 扩散到 2.8，opacity 从 0 到 0.7 再到 0

#### 场景:呼吸动画支持减少动画偏好
- **当** 用户系统启用 prefers-reduced-motion: reduce
- **那么** 呼吸动画和波纹动画必须停止，鹅卵石保持静态显示
