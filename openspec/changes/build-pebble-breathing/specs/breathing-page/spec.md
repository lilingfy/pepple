## 新增需求

### 需求:呼吸圆 CSS 动画
系统必须通过 CSS `@keyframes` 实现呼吸圆缩放动画，总周期 19s，吸气阶段（0-21%，约 4s）scale 从 1 放大到 1.35，屏息阶段（21-58%，约 7s）保持 scale 1.35，呼气阶段（58-100%，约 8s）scale 从 1.35 缩小到 1。

#### 场景:页面加载自动开始呼吸动画
- **当** 用户进入 `/breathing` 路由
- **那么** 呼吸圆立即开始 19s CSS 动画循环，无需点击启动

#### 场景:呼吸动画与文案同步
- **当** CSS 动画进入不同阶段
- **那么** 中文文案（吸气/屏息/呼气）和英文文案（DEEP INHALE/HOLD GENTLY/SLOW EXHALE）必须同步切换

---

### 需求:倒计时联动
系统必须显示从 01:59 开始的倒计时，每秒递减，到 00:00 停止。倒计时必须与呼吸动画同步暂停和继续。

#### 场景:倒计时与呼吸动画同步开始
- **当** 页面加载
- **那么** 倒计时从 01:59 开始递减

#### 场景:倒计时到零停止
- **当** 倒计时到达 00:00
- **那么** 系统停止倒计时，不得继续递减至负数

---

### 需求:点击暂停/继续
系统必须支持点击呼吸圆暂停所有动画（呼吸圆缩放、文案切换、倒计时），再次点击继续播放。

#### 场景:点击呼吸圆暂停
- **当** 用户点击呼吸圆
- **那么** 呼吸圆 CSS 动画、文案动画、倒计时全部暂停

#### 场景:再次点击继续
- **当** 用户在暂停状态点击呼吸圆
- **那么** 呼吸圆 CSS 动画、文案动画、倒计时全部恢复播放

---

### 需求:可访问性适配
系统必须检测 `prefers-reduced-motion` 媒体查询。在减少动画模式下，禁止执行呼吸圆缩放和文案切换动画，仅保留静态显示，倒计时功能不受影响。

#### 场景:减少动画模式下禁用动画
- **当** 用户设备启用 `prefers-reduced-motion`
- **那么** 系统禁止执行呼吸圆 scale 动画和文案切换动画

#### 场景:减少动画模式下功能保持
- **当** 用户设备启用 `prefers-reduced-motion`
- **那么** 倒计时继续正常运行，点击暂停/继续功能仍然可用

---

### 需求:离线运行
急救呼吸页面必须完全离线可用，禁止依赖任何后端接口或网络请求，所有状态和动画逻辑必须在客户端运行。

#### 场景:无网络连接时正常运行
- **当** 用户在无网络环境下访问 `/breathing`
- **那么** 页面必须正常加载并完整执行呼吸引导，不出现任何错误或降级提示

---

### 需求:视觉还原
系统必须还原设计稿 `pebble_breathing.html` 第二版的视觉设计，包括：
- 正圆呼吸圆（非鹅卵石形状）
- 背景浮动模糊球体（`ambientFloat` 动画）
- 标题区装饰星星
- 倒计时卡片带分隔线和"AI 引导中"标识
- Header 导航栏和 Footer 页脚

#### 场景:视觉元素完整
- **当** 用户访问 `/breathing`
- **那么** 页面必须显示与设计稿一致的 Header、标题区、呼吸圆、引导文案、倒计时卡片、Footer
