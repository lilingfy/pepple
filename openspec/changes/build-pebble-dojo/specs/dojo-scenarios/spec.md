# 场景选择规范

## 概述

场景选择模块提供三种预设练习场景，包含场景标签、心理语境描述和技巧锦囊。

## ADDED Requirements

### 需求:支持三种预设场景切换
系统必须提供"职场越界"、"亲密关系"、"社交应对"三种场景，用户可通过标签切换。

#### 场景:切换场景标签
- **当** 用户点击场景标签（如"亲密关系"）
- **那么** 该标签高亮显示，左侧心理语境和技巧锦囊同步更新

#### 场景:场景顺序固定
- **当** 页面加载或切换场景
- **那么** 三个场景顺序固定为：职场越界、亲密关系、社交应对

### 需求:场景数据必须包含完整元信息
每个场景必须包含 id、name、description、difficulty、context、goal、tips 字段。

#### 场景:获取场景列表
- **当** 系统调用 `GET /api/scenarios`
- **那么** 返回包含三个场景的完整数据，每个场景包含所有必需字段

### 需求:心理语境必须显示情境描述和达成目标
左侧上下文卡片必须显示当前场景的情境描述和达成目标提示。

#### 场景:显示职场越界语境
- **当** 用户选择"职场越界"场景
- **那么** 心理语境卡片显示对应情境描述（如"一位资深同事试图让你在周末无偿加班..."）和达成目标（如"维持职业边界，不JADE"）

### 需求:技巧锦囊必须显示适用技巧列表
技巧锦囊必须显示当前场景适用的灰岩应对技巧，每项包含名称和说明。

#### 场景:查看技巧锦囊
- **当** 用户选择任意场景
- **那么** 技巧锦囊卡片显示 2-4 条该场景适用的技巧，格式为"技巧名: 说明"

### 需求:场景切换必须重置会话状态
切换场景时必须清空当前消息历史，创建新会话。

#### 场景:切换场景重置会话
- **当** 用户在对话中切换到另一场景
- **那么** 中央聊天区清空，显示新场景的开场白
