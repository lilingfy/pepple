# 聊天对话系统规范

## 概述

聊天对话系统是陪练场的核心交互区域，支持 AI 角色扮演和用户回复，消息气泡必须符合鹅卵石视觉风格。

## ADDED Requirements

### 需求:消息气泡必须符合设计规范
AI 消息气泡位于左侧，使用 slate-200/80 背景色，圆角为 `0.5rem 2rem 2.5rem 2rem`；用户消息气泡位于右侧，使用 moss-green/60 背景色，圆角为 `2rem 0.5rem 2rem 2.5rem`。

#### 场景:AI 发送消息
- **当** AI 回复用户消息
- **那么** 消息气泡显示在左侧，背景 slate-200/80，圆角 `0.5rem 2rem 2.5rem 2rem`，头像使用金色主题

#### 场景:用户发送消息
- **当** 用户发送回复
- **那么** 消息气泡显示在右侧，背景 moss-green/60，圆角 `2rem 0.5rem 2rem 2.5rem`，头像使用安全绿主题

### 需求:消息列表必须支持滚动
聊天容器必须支持垂直滚动，自定义滚动条样式（宽度 4px，滑块安全绿色）。

#### 场景:长消息列表滚动
- **当** 消息数量超过可视区域
- **那么** 用户可滚动查看历史消息，滚动条符合设计规范

### 需求:输入区必须包含发送按钮和工具栏
输入区必须包含圆角输入框、鹅卵石形状发送按钮，底部工具栏提供语音输入和重启本局入口。

#### 场景:用户输入消息
- **当** 用户在输入框输入文字
- **那么** 可点击发送按钮或按 Enter 发送消息

#### 场景:重启当前会话
- **当** 用户点击"重启本局"
- **那么** 清空当前消息历史，保留当前场景，重新开始对话

### 需求:必须显示 AI 输入指示器
当 AI 正在生成回复时，必须显示打字指示器（如"对方正在输入..."或动画点）。

#### 场景:AI 正在回复
- **当** 用户发送消息后等待 AI 回复
- **那么** 聊天区显示打字指示器，提示用户等待

### 需求:必须处理发送失败状态
当消息发送失败时，必须显示错误提示，并提供重试机制。

#### 场景:网络异常重试
- **当** 消息发送因网络异常失败
- **那么** 显示错误提示，用户可点击重发按钮重新发送
