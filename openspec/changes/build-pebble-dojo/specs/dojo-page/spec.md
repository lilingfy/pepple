# 模拟陪练场页面规范

## 概述

陪练场页面是 Pebble AI 的核心练习功能，采用三栏固定布局，为用户提供沉浸式的灰岩应对练习环境。

## ADDED Requirements

### 需求:页面采用三栏固定布局
页面必须使用三栏网格布局，桌面端左侧 3 列（场景面板）、中间 6 列（聊天区）、右侧 3 列（分析面板）。

#### 场景:桌面端显示三栏布局
- **当** 用户在桌面端访问 `/dojo` 页面
- **那么** 页面显示左中右三栏布局，各栏内容完整可见

#### 场景:移动端侧边栏折叠
- **当** 用户在移动端访问 `/dojo` 页面
- **那么** 中央聊天区全屏显示，左右侧边栏可折叠/抽屉式展开

### 需求:页面视觉风格必须符合鹅卵石设计系统
页面必须使用玻璃拟态卡片、鹅卵石圆角、柔和安全感配色（灰岩蓝 #7D8C9F、安全绿 #A8D8B9、背景色 #F0F6F2）。

#### 场景:页面加载时视觉检查
- **当** 页面加载完成
- **那么** 背景显示流体渐变，卡片使用 glass-card 样式，按钮使用鹅卵石圆角

### 需求:页面响应式设计
页面必须适配桌面端（≥1024px）和移动端（<768px），确保完整会话流程在所有设备上可用。

#### 场景:桌面端完整会话
- **当** 用户在桌面端完成一次完整演练
- **那么** 场景切换、消息收发、分析面板更新均正常可用

#### 场景:移动端完整会话
- **当** 用户在移动端完成一次完整演练
- **那么** 通过折叠/展开侧边栏，可完成场景选择、聊天、查看分析的全流程
