# 实时情绪分析面板规范

## 概述

右侧分析面板实时展示用户回复的情绪中性度得分、等级评价和陪练建议。

## ADDED Requirements

### 需求:必须显示圆形情绪得分圆环
面板必须包含圆形进度条，中心显示 0-100 分得分，进度条颜色随分数变化。

#### 场景:优秀得分显示
- **当** 用户得分在 80-100 分
- **那么** 圆环显示安全绿色（#A8D8B9），中心显示具体分数

#### 场景:良好得分显示
- **当** 用户得分在 60-79 分
- **那么** 圆环显示黄色（#FCD34D），中心显示具体分数

#### 场景:一般得分显示
- **当** 用户得分在 40-59 分
- **那么** 圆环显示橙色（#FB923C），中心显示具体分数

#### 场景:需改进步显示
- **当** 用户得分在 0-39 分
- **那么** 圆环显示红色（#F87171），中心显示具体分数

### 需求:得分变化必须有动画过渡
当用户新回复的得分返回时，圆环必须从旧分数动画过渡到新分数，持续约 1000ms。

#### 场景:得分提升动画
- **当** 用户得分从 60 提升到 85
- **那么** 圆环平滑动画到 85 分位置，颜色相应变化

### 需求:必须显示等级标签和评语
面板必须显示"中性度得分: {等级}"标签和对应评语。

#### 场景:优秀等级评语
- **当** 用户获得 80-100 分
- **那么** 标签显示"中性度得分: 优秀"，评语为"你成功识别了情绪陷阱。当前语气非常克制，有效避免了对抗性升级。"

### 需求:必须显示即时反馈和注意点
面板必须显示针对用户上一条回复的即时反馈和预警注意点。

#### 场景:显示即时反馈
- **当** 用户发送消息后收到分析结果
- **那么** 即时反馈区域显示做得好的地方（如"简洁有力，未陷入'解释'陷阱"）

#### 场景:显示注意点
- **当** 分析检测到潜在情绪陷阱
- **那么** 注意点区域显示预警（如"对方可能在试图激怒你，不要被'团队精神'带节奏"）

### 需求:必须包含结束演练按钮
面板底部必须包含全宽"结束演练"按钮，使用鹅卵石圆角，点击后结束当前会话并显示总结。

#### 场景:结束演练
- **当** 用户点击"结束演练"按钮
- **那么** 调用 `POST /api/simulator/[sessionId]/end`，显示会话总结

### 需求:rightPanel 字段必须与后端契约一致
面板必须正确显示后端返回的 `analysisScore`、`analysisLabel`、`analysisSummary`、`instantFeedback`、`attentionPoint` 五个字段。

#### 场景:解析后端响应
- **当** 后端返回 simulator 响应
- **那么** 面板正确映射并显示 rightPanel 中的五个字段
